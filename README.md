# 对拍

中文名：**对拍** · 前缀 `duet` · 端口 **7800**

## 骨架（新骨，不是闸对/缝包换皮）

**左轨装载 → 右轨装载 → 同键对齐落差 → 单边悬账 → 对拍结论**

| 对比 | 闸对 | 缝包（已弃） | **对本仓** |
| --- | --- | --- | --- |
| 拓扑 | 单流入→在途→成物 | 单流入→在途→成物 | **双轨独立装载→键对齐** |
| 在途态 | 开腿账 | 拼缝账 | **无开腿/拼缝；悬账是对齐后单边** |
| 产物 | 行程账 | 整件账 | **对齐差 + 对拍结论** |
| 旁路名 | 旁路匣 | 旁路匣 | **悬账单（命名与语义都不同）** |

皮：支付渠道回执 vs 核心记账。去皮：**双源键对齐管道**。禁止做成收银 CRUD、报表看板、工单系统。

## 对拍结论三联贯验（已落）

`对拍结论` 页顶策略卡片可择形态跑贯验结论，结论徽章与对齐差/悬账单/旁路账册三表同票：

- **形态二择一**（轨规 `贯验形态` 或跑时指定）：`三联`＝差+悬+旁路账册三联互证，旁路账册行参与撕裂计数；`双联附件`＝差+悬双联判撕裂，旁路账册不进撕裂计数、落 `贯验快照` 表附件可回读。
- **撕裂规则**：纯对齐不撕裂；有旁路账册无悬——三联撕裂、双联附件不撕裂（有快照附件）；有悬两边均撕裂。
- **硬约束**：贯验锁——并发跑结论只许单成功（其余 409）；三表计数读 + 结论/快照落库同事务同成败；旁路升格与贯验跑同锁，计数不漂；`GET /api/三联贯验` 只读现算，valid＝不撕裂且最新入库结论与三表同票。

接口：`POST /api/对拍结论/贯验跑`（体可带 `形态`）· `GET /api/三联贯验` · `GET /api/贯验结论` · `GET /api/旁路账册` · `POST /api/旁路账册/升格`（体带 `编号` 或 `业务键`）· `GET /api/贯验快照` · `GET /api/贯验快照/{sid}`。
